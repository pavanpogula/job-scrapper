# Frontend Design & Visual Polish
When modifying UI components, pages, or styling in `frontend/src/**/*.tsx`:
1. Source of truth for product definition and craft floor is `PRODUCT.md` and `DESIGN.md` at the repository root.
2. Consult the `impeccable` skill for art direction, component polish, motion, and UX consistency.
3. Adhere to design system tokens and component hierarchy rather than inline ad-hoc styles.
4. Ensure layout responsiveness across mobile, tablet, and desktop breakpoints.
5. Verify that loading skeletons, empty states, and error alerts match the application's visual polish standards.
