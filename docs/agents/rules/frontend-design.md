# Frontend Design & Visual Polish
When modifying UI components, pages, or styling in `frontend/src/**/*.tsx`:
1. Consult the `impeccable` skill for art direction, component polish, motion, and UX consistency.
2. Adhere to design system tokens and component hierarchy rather than inline ad-hoc styles.
3. Ensure layout responsiveness across mobile, tablet, and desktop breakpoints.
4. Verify that loading skeletons, empty states, and error alerts match the application's visual polish standards.
